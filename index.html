Discovery Notes

1. What this sniffs

Readable runtime properties on window.nzxt, readable runtime properties on window.nzxt.v1, and every payload path observed via onMonitoringDataUpdate.

2. What this cannot guarantee

Non-readable private internals, hidden state inside native code, inaccessible closures, or internal webview objects that are not exposed to JavaScript.

3. Why this is stronger than a static schema

It does not rely only on documented types. It also unions real runtime payload paths that actually appear while CAM is running on your system.
